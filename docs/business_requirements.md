# Бизнес-требования

## Назначение приложения

Учебное приложение для анализа бизнес-метрик предприятия.

## Целевая аудитория

Малый и средний бизнес, аналитики, менеджеры.

## Функциональные требования

- Расчёт выручки за период
- Расчёт рентабельности
- Вывод таблицы метрик
- Построение графиков динамики

## Нефункциональные требования

- Python 3.10+
- Работа в виртуальном окружении
- Кроссплатформенность (macOS, Windows, Linux)

## Ограничения

- Данные вводятся вручную или из CSV
- Без подключения к базе данных
